Este projeto é exclusivamente para **pesquisa, backtest e educação**.

- Não coloca ordens reais em nenhuma corretora.
- Não é aconselhamento financeiro.
- Backtest **não** garante desempenho futuro.
- Crypto é volátil; alavancagem pode causar perda total.
